## 九、关键成功因素（CSF）

1. **接口设计第一**
   - 定义好LocalizationBase和数据格式，后续容易扩展
   - 坏的接口会导致后期返工

2. **模块独立可运行**
   - 每个模块都要有run.py，支持单独调试
   - 避免"只能整体运行"的耦合

3. **自动化才能成功**
   - 参数扫描必须全自动化，否则耗时无法承受
   - PowerShell脚本完成后，一键启动4周期实验

4. **统计检验不能省**
   - CEP50差1%看起来很小，但可能无统计显著性
   - Wilcoxon检验成本极低（一行代码），收益大（学术严谨性）

5. **文档即代码**
   - README.md必须在开发时同步编写，不能最后补
   - 好的README能让新人2小时上手，坏的让人花2天
