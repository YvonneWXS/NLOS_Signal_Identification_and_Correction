## 六、核心发现

### 成功之处

1. **Fix 6A 精准修复 berlin2**: σ分离比从 0.98→1.27，per-sample contrastive loss 直接监督每个样本的 σ_los vs σ_nlos 关系。

2. **Fix 6B 消除尖峰**: frankfurt1 σ_nlos 从最高 57km 降至 <12.2km，log-space 硬 clamp + sigma head 单独梯度裁剪双重保障。

3. **Fix 6D 有效**: frankfurt2 FP 率下降 2.2%，自动 pos_weight 机制在不同数据集间自适应。

### frankfurt1/2 σ分离仍失效的原因

- frankfurt1: **σ_nlos(LOS) > σ_nlos(NLOS)** (0.91 > 0.87)，完全反转
- frankfurt2: σ_nlos(LOS)=0.90 vs σ_nlos(NLOS)=0.94，几乎无分离

**根本原因**: 这不是损失函数的问题，而是 BCE+NLL 架构的本质限制——当 p_los 分类足够好时，NLL loss 倾向于让所有 σ 都变小，而不是按标签分离 σ。

### p_los gap 下降 (berlin1/2)

动态 BCE 权重衰减过快，50 epoch 后 BCE 权重已降至 ~1.0，对 p_los 的监督减弱。

## 七、下一步建议（优先级排序）

### P0: frankfurt σ 分离根本性修复
- **方案**: 引入 explicit σ supervision（直接用标签监督 σ_los(NLOS样本) > σ_los(LOS样本) + margin），而非仅依靠 NLL loss 的隐式梯度
- **预期**: frankfurt1 分离比从 0.96 → >1.15

### P1: BCE 权重不衰减太快
- **方案**: 将 BCE 权重衰减的斜率从 0.6 降至 0.3（即 1.5→1.05 而非 1.5→0.6）
- **预期**: p_los gap 恢复至 >0.55

### P2: frankfurt2 F1 提升
- 当前 F1=0.784，距目标 0.800 差 0.016
- FN 率高达 20.6%（高仰角 NLOS 最难检测）
- **方案**: 加入仰角-aware 特征增强或星座特定的 head
