# Changelog

- Complete code restructuring: 5 modules with unified interfaces
- 13 localization methods (5 existing + 8 new) via factory pattern
- Common library: coordinate transforms, SP3 reader, metrics, time utils
- Baseline comparison: 4 datasets x 13 methods with SP3 satellite positions
- Statistical tests: Wilcoxon signed-rank on all method pairs
- Parameter sweep: hard threshold + MoG ablation
- 9 publication-ready figures (CDF, boxplot, heatmap, radar, trajectory)
- Functional PowerShell batch scripts for experiment automation
