# 恢复混合高斯输出 (MoG) + V2026→V2025 合并 — 最终实施计划（修订版）

## 摘要

三步走：① 将 GAT_V2026 的向量化 GAT + block-diagonal batching 迁移到 GAT_V2025.py；② 在合并后的 GAT_V2025.py 上实现 MoG 输出（p_los + μ_NLOS + σ_NLOS）与三阶段渐进训练；③ 更新 analyze_experiment.py、generate_report.py、run_full_training.py 对齐。最终只有 GAT_V2025.py 一份主代码，V2026 保留为备份。

---

## 设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| LOS σ | 固定 2.0m（可配置 `SIGMA_LOS_FIXED`） | 避免增加学习自由度，GPS 伪距精度通常在 1-5m |
| μ_NLOS 激活 | Softplus，初始值 ≈ 50m | 保证正值，符合 NLOS 正偏物理直觉 |
| σ_NLOS 范围 | clamp [2m, 200m] | 覆盖城市峡谷 NLOS 误差典型范围 |
| 训练策略 | **三阶段渐进切换**（见下） | 避免硬切换导致的 loss 突变和梯度不稳定 |
| μ 正则 | `LAMBDA_MU_REG = 0.001`（初期较强） | 防止 μ 过早学得过大 |

---

## 三阶段渐进训练策略（替代原双阶段）

```
Epoch  1–20:  纯 BCE（阶段一）
              - 冻结 mu_nlos_head 和 log_sigma_nlos_head
              - Loss = λ_bce·BCE + λ_ent·Entropy + λ_elev·ElevPrior
              - 目标：p_los 学到可用状态

Epoch 21–35:  BCE + MoG NLL 混合过渡（阶段二）
              - 解冻 mu/sigma 头
              - λ 从 1.0 线性衰减到 0.0
              - Loss = λ·Loss_BCE + (1-λ)·Loss_MoGNLL + Entropy + ElevPrior + μ/σ L2
              - 目标：平滑引入 MoG NLL，mu/sigma 头逐步激活

Epoch 36–100: 纯 MoG NLL（阶段三）
              - Loss = Loss_MoGNLL + Entropy + ElevPrior + μ/σ L2
              - 目标：完整建模 NLOS 误差分布
```

λ 衰减公式（epoch 21–35，共 15 个 epoch）：
```
λ(epoch) = 1.0 - (epoch - 20) / 15.0
```

## 变更清单（6 个文件）

### 文件 1：`GAT_V2025.py` — 七处核心改动

**A. GATLayer.forward() 向量化**（替换 L61–L92）

将 Python for-loop 逐边遍历替换为 `index_add_` 向量化版本：

```python
def forward(self, x, edge_index):
    if x.dim() == 1: x = x.unsqueeze(0)
    N, h, D = x.size(0), self.heads, self.out_features
    x_hat = torch.mm(x, self.W).view(N, h, D)
    out = torch.zeros(N, h, D, device=x.device, dtype=x_hat.dtype)
    if edge_index.size(1) > 0:
        att_weight = F.softmax(self.att.view(-1), dim=0)
        src, dst = edge_index[0].long(), edge_index[1].long()
        mask = (src < N) & (dst < N)
        src, dst = src[mask], dst[mask]
        for head_idx in range(h):
            msgs = x_hat[src, head_idx, :] * att_weight[head_idx]
            out[:, head_idx, :].index_add_(0, dst, msgs)
    else:
        out = x_hat
    if self.concat: out = out.view(N, -1)
    else: out = torch.mean(out, dim=1)
    return out
```

**单元测试要求**：迁移后用 1 个历元的数据对比新旧 forward 输出的 `torch.allclose(rtol=1e-5, atol=1e-7)`，确保数值完全一致。

**D. MoGNLLLoss 类**（新增约 L310 之后）

保留 NLOSLoss 用于阶段一/二。新增独立的 MoGNLLLoss：

```python
class MoGNLLLoss(nn.Module):
    def __init__(self, sigma_los=2.0, lambda_entropy=0.03,
                 lambda_elevation=0.1, lambda_mu_reg=0.001, lambda_sigma_reg=0.001):
        ...

    def forward(self, p_los, mu_nlos, log_sigma_nlos, err, label, elevation=None):
        # 数值稳定：log-sum-exp
        sigma_nlos = torch.clamp(torch.exp(log_sigma_nlos), 2.0, 200.0)
        p_safe = torch.clamp(p_los, 1e-6, 1.0 - 1e-6)

        log_prob_los  = -0.5 * (err / self.sigma_los) ** 2 - math.log(self.sigma_los) - 0.5 * math.log(2 * math.pi)
        log_prob_nlos = -0.5 * ((err - mu_nlos) / sigma_nlos) ** 2 - torch.log(sigma_nlos) - 0.5 * math.log(2 * math.pi)

        # logsumexp trick for stability
        log_p_los = torch.log(p_safe)
        log_p_nlos = torch.log(1.0 - p_safe)
        max_log = torch.max(log_p_los + log_prob_los, log_p_nlos + log_prob_nlos)
        log_mix = max_log + torch.log(
            torch.exp(log_p_los + log_prob_los - max_log) +
            torch.exp(log_p_nlos + log_prob_nlos - max_log)
        )

        nll = -log_mix.mean()
        reg = self.lambda_mu_reg * (mu_nlos ** 2).mean() + self.lambda_sigma_reg * (log_sigma_nlos ** 2).mean()
        ...
```

**E. train_epoch 三阶段逻辑**（修改 L359–L540）

if is_pure_bce:

## 回退方案

| 问题 | 方案 |
|------|------|
| 阶段二 loss 突变 | 延长 `MOG_BLEND_EPOCHS` 到 25，降低 LR 到 3e-5 |
| σ 爆炸 / μ 发散 | 增大 `LAMBDA_MU_REG` 到 0.01，减小 `SIGMA_NLOS_MAX` 到 100m |
| p_los 坍缩 | 回退到纯 BCE 训练（阶段三不启用），仅做 MoG 推理 |
| V2026→V2025 迁移数值不一致 | 切回 V2026，MoG 改动同步写入 V2026 |
| 完全失败 | 回退 `GAT_V2025.py.backup`，用 exp_001–004 结果汇报 |

## 假设

1. 向量化 GATLayer 的数值等价性可通过单元测试验证（exp_001–004 已隐式验证）
2. 固定 LOS σ=2m 在 GPS L1 伪距精度范围（1-5m）内合理
3. Block-diagonal batching 兼容三元组输出（仅影响前向传播宽度，不需要改 collate）
4. 伪距误差单位统一为 km
